# Editor Checklist — Claude Code editing an @blkgrlco video

Run top to bottom on every @blkgrlco edit. Her checklist, received
2026-11-13 (verbatim: `../brand-bible/source/blkgrlco-editor-checklist-2026-11-13.md`),
built from her Nov 11 reset and the retention video. **(kept)** marks an
older rule that still stands. Story-type guidance per video lives in
`../brand-bible/brands/blkgrlco.md` → HHH Weekly Edit Breakdown.

## 1. Before the build
- [ ] Read all footage and write the master footage doc
      (`_footage-master.md`, as BLKGRLCO Bin writes it).
- [ ] State the one story in one line: question → context → attempt →
      honest result → takeaway.
- [ ] Write the hook (a real number or thing, said in the first 5
      seconds) and check it matches the title's promise.
- [ ] Apply the D-Log M to Rec.709 LUT, then reframe with her face
      centered. **(kept)**

## 2. Edit list (sent to her before any render)
- [ ] Each clip gets a one-line reason it's there, plus what changed from
      the clip before. If nothing changed, cut it.
- [ ] B-roll must show what she's saying. Remove decorative shots.
- [ ] Pop-ups and on-screen text land when she says it, not early.
- [ ] Punch-ins only on real reactions. **(kept)**
- [ ] The honest result gets its full time, even a missed goal. **(kept)**
- [ ] The takeaway answers the question the video opened with.

## 3. Low-res preview review
- [ ] First 5 seconds confirm the title and thumbnail promise.
- [ ] Every section has something the viewer is waiting for.
- [ ] No section repeats an idea already shown.
- [ ] Judged on curiosity, cut, clarity and connection. Only the best
      version is sent.

## 4. House rules (kept)
- [ ] No employer or job named or shown.
- [ ] Phone on screen only when essential.
- [ ] Skincare: no product labels, no sound effects.
- [ ] YouTube uses original stickers only. TikTok/IG stickers come from
      her cue list.
- [ ] Poppins for @blkgrlco only.

## 5. Before posting
- [ ] She signs off.
- [ ] Every long-form has three thumbnails (real photos, never
      AI-looking) and three titles.
- [ ] Posting time and order are correct: 3:00 PM CT, in numerical order.
