# BLKGRLCO Studios — notes for Claude Code

## Inbox: read first, every session

Omnia's Claude assistant (chat) talks to Code through `_inbox/`:

- `_inbox/from_chat.md`: hers. Read it at the start of every session and
  again before reporting. Never edit it. Newest entry wins. `HOLD: <topic>`
  means don't act on that topic.
- `_inbox/from_code.md`: yours. Add a report, newest on top, using the
  format at the top of the file, whenever you finish, get blocked, or need
  her on something raised in `from_chat.md`.

The podcast has its own inboxes with the same protocol:
`podcast/_inbox/` (show-level) and `podcast/episodes/epNN/_inbox/`
(per episode). Route each message to the most specific inbox that fits.

## Standing rules

- Nothing publishes or goes to a platform without her sign-off (see
