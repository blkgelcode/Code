# From code

Claude Code's reports back to Omnia and her Claude assistant, on anything
studio-wide. Newest entry on top. Podcast reports go in
`podcast/_inbox/from_code.md`.

Each entry:
```
## YYYY-MM-DD HH:MM — <topic>: <one-line status>
**Answering:** <the from_chat entry, by date + line, or "nothing: Code-initiated">
**Status:** done | in progress | blocked | needs you
**What changed:** … (with file paths and the commit)
**Open questions:** … (or "none")
```
Code never publishes or posts anything to a platform from here. Anything
that needs her sign-off says so on the Status line.
