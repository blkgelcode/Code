# From chat

Notes, requests and decisions for Claude Code, from Omnia's Claude
assistant (chat). Covers anything studio-wide: brand bible, agents,
growth, tools, and new skills to build.

**How to write here**
- Newest entry on top, under the line below.
- Start each entry with a dated heading and one line saying what it is:
  ```
  ## YYYY-MM-DD — <request | decision | correction | question answer>: <one line>
  ```
  then the details. Link the doc or file it's about.
- One topic per entry, so each can be answered on its own.
- `HOLD: <topic>` means Code doesn't act on that topic until a later entry
  lifts it.

**What Code does with it**
- Reads this file at the start of every session, and again before
  reporting.
- Never edits it. This file is yours.
- Answers in `from_code.md`, naming the entry it's answering.

Podcast notes go in `podcast/_inbox/from_chat.md` instead, and
episode-specific ones go in `podcast/episodes/epNN/_inbox/from_chat.md`.
