# Weekly Content Intelligence Report — Template

Copy this template each week once there's enough published content and
analytics history to fill it with real findings (not before — an empty
report with invented numbers is worse than no report).

Date range: `[YYYY-MM-DD]` to `[YYYY-MM-DD]`

1. **Best-performing content** — what, and by which metric
2. **Worst-performing content** — what, and by which metric
3. **Biggest audience insight** — one thing learned about the audience this week
4. **Emerging trends** — relevant to this brand specifically, with priority tag
5. **New content opportunities** — surfaced by research/analytics this week
6. **Recommended long-form videos**
7. **Recommended Shorts/Reels/TikToks**
8. **Thumbnail lessons**
9. **Title lessons**
10. **SEO opportunities**
11. **Competitor insights**
12. **Experiments to run next**
13. **Content to stop making** — with reasoning
14. **Content to make more of** — with reasoning
15. **Next week's recommended content calendar**

Any finding here that gets acted on repeatedly should be promoted into
`brand-bible/CREATIVE_MEMORY.md` as a confirmed pattern.
