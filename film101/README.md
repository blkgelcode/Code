# Film 101 — Ugly Duckling Studios

Episode pipeline for the Film 101 series. Brand rules live in
`../brand-bible/brands/uglyducklingstudios.md`.

| Command | Input | Output |
|---|---|---|
| "Package Episode N" | `episodes/epNN/Episode_NN_to_strategy.md` + candidate frames in `episodes/epNN/frames/` | Package in chat + `Episode_NN_to_editor.md` |
| "Review Episode N" | Pasted numbers (impressions, CTR, avg view duration, drop-off points) | `Episode_NN_lessons.md` |
| "Plan the next four weeks" | — | Content calendar in chat |

Frames: name each candidate by its timestamp, e.g. `frames/03m12s.jpg`.

Not in this pipeline: her short film (it has its own channel).
