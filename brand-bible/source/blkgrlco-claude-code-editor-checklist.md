# Claude Code Editor Checklist

One checklist for every @blkgrlco edit. Built from the Nov 11 workflow reset plus retention, motion and shot-variety tips.

## Shoot day (new)

- [ ] Coverage: at least 5 shot types per scene: wide to establish, medium for action and talking, close-up for emotion, an insert for a specific detail, and one creative shot.
- [ ] Mechanical moments (walking in, pouring, setting things down): shoot at least 3 takes at different energy levels.
- [ ] Reactions and the honest result: one real take, no redo.
- [ ] Mix a few great b-roll shots with simple handheld shots of her talking through the struggle, so the contrast holds attention.
- [ ] Not every frame has her in it. Use objects and the environment, and stay behind the camera sometimes.
- [ ] On a tripod, move something in the frame (her body or an object) instead of the camera.
- [ ] Write down every "wouldn't it be cool" idea, then shrink it to what she can film alone.

## 1. Before the build

- [ ] Read all footage and write the master footage doc.
- [ ] State the one story in one line: question → context → attempt → honest result → takeaway.
- [ ] Write the hook (a real number or thing, said in the first 5 seconds) and check it matches the title and thumbnail promise.
- [ ] Apply the D-Log M to Rec.709 LUT, then reframe with her face centered.

## 2. Edit list (sent before any render)

- [ ] Every clip gets a one-line reason it's there, plus what changed from the clip before. If nothing changed, cut it.
- [ ] Simplify: remove context the viewer doesn't need.
- [ ] B-roll must show what she's saying. Remove decorative shots.
- [ ] Pop-ups and on-screen text land on the exact word, never early. If early, wait about 2 seconds.
- [ ] Shot variety from real footage: wide to establish, tight detail, low angle, close-up on a reaction.
- [ ] Punch-ins only on real reactions, with a hold (identical keyframes) before the move.
- [ ] Cut dead air in talking-heads. Keep a pause only when it carries the moment.
- [ ] The honest result, including a missed goal, gets its full time. Don't rush the payoff.
- [ ] The takeaway answers the question the video opened with.

## 3. Motion specs

- [ ] Pop-ups: scale 0 → 105% → 100%, opacity 0 → 100, and position sliding in from the edge, over 8–10 frames.
- [ ] Titles: slide in from off-screen with ease-in on the end keyframe. Optional opacity fade 0 → 100.
- [ ] PNG titles go on the track above footage, keyframed in the same way.

## 4. Low-res preview review

- [ ] First 5 seconds confirm the title and thumbnail promise.
- [ ] Every section has something the viewer is waiting for.
- [ ] No section repeats an idea already shown.
- [ ] Judged on curiosity, cut, clarity and connection. Send only the best version.

## 5. House rules

- [ ] No employer or job named or shown.
- [ ] Phone on screen only when essential.
- [ ] Skincare: no product labels, no sound effects.
- [ ] YouTube uses original stickers only. TikTok/IG stickers come from her cue list.
- [ ] Poppins for @blkgrlco only.

## 6. Before posting (watch time and thumbnails are the priority through Dec 22)

- [ ] She signs off.
- [ ] Every long-form has three thumbnails (real photos, never AI-looking) and three titles.
- [ ] Every long-form is cut into a Short that starts mid-action.
- [ ] Posted at 3:00 PM CT, in numerical order.
