BLKGRLCO: PLATFORM PACKAGING CHECKLIST

CORE STORY
[ ] Keep the video connected to my 90-day Hot, Happy, Healthy challenge.
[ ] Identify the intended viewer, specific situation, and honest payoff.
[ ] Lead with the episode’s story; keep “Day [verified number]/90” secondary.
[ ] Preserve my personality, privacy, and actual experience. Never invent results.

YOUTUBE LONG-FORM — ONLY WHEN REQUESTED
[ ] Write an accurate title built around a clear question, task, or outcome.
[ ] Suggest a complementary thumbnail that communicates one main idea.
[ ] Make the opening deliver the title/thumbnail promise without a long introduction.

YOUTUBE SHORTS
[ ] Open with relevant action or a clear spoken premise, not a static cover.
[ ] Write a standalone title and select a representative thumbnail frame.
[ ] Resolve the opening question without padding or a forced runtime.

TIKTOK
[ ] Choose a relatable situation or specific search intent.
[ ] Use natural topic language in the opening, on-screen text, and caption.
[ ] Label search phrases “unvalidated” unless actual search data supports them.
[ ] Use a clear cover label; include trends or hashtags only when relevant.

INSTAGRAM REELS
[ ] Open with a recognizable situation, feeling, or useful action.
[ ] Create a readable cover and a caption combining the topic with personal meaning.
[ ] Give viewers a genuine reason to relate, save, or share. Avoid engagement bait.
[ ] Export from a clean master without another platform’s visible watermark.

PRODUCTION AND TESTING
[ ] Reuse the core edit. Generate only the platform versions I request.
[ ] Avoid invented algorithm weights, hashtag quotas, and universal duration targets.
[ ] Choose one packaging element to test within each platform.
[ ] Compare similar posts at the same age; keep platform metrics separate.
[ ] Do not claim improved performance until actual audience data supports it.

RETURN FOR EACH REQUESTED PLATFORM
- Title or caption
- Cover text, thumbnail concept, or selected frame
- Opening line and on-screen text
- Intended viewer and story promise
- One test hypothesis and metrics to review

Do not publish, schedule, or overwrite originals without authorization.
