# @blkgrlcotoo — Travel (Brand Breakdown)
*Part of BLKGRLCO Studios. Pair with `BLKGRLCO-STUDIO-OVERVIEW.md` for shared context (creator bio, production reality, tools, voice rules, thumbnail workflow).*

---

## Identity
- Series: **"Young & Outside in [Location]"** — renamed 2026-08 from "Young Hot & Outside" (itself renamed from "Fuck It Book It" / "STAMPED"). Blank fills with the country/city per episode.
  - **Never use retired names:** "Young Hot & Outside," "Fuck It Book It," "STAMPED."
- Recurring series: **SCENT PASSPORT**.

## Production Constraints
- Only filmed on vacation days or weekend offs — never squeezed into a weekday capture window. (This is the one BLKGRLCO brand explicitly exempt from the weekday-opportunistic-capture rhythm that governs the other two.)

## Brand Palette
- No fixed palette locked yet. Pull color direction from the actual destination/footage rather than defaulting to a generic travel-thumbnail teal-and-orange grade. Ask if a look hasn't been set for a given trip/series entry rather than inventing one.

## Editorial Frameworks That Apply Here
- From the Narrative Cuts reference (Tim Runia): **Wide → Medium → Close** is the standard scene-establishing tool for a new location; **Flow Cut** works well for transit/movement footage.
- From the Graphics/SFX reference (Yale Jeannette): alongside @blkgrlco, this brand's shorts/explainer-style content is a stated fit for the fast-cut, graphic-heavy pop-up/SFX style (opposite of the podcast's documentarian rule). Nothing locked in yet — flag when ready to build overlay assets.

## SEO / Hashtags / Titles / Descriptions
**Core terms:** destination name + genre terms (solo travel, travel vlog, [country/city] travel, budget travel, Black traveler) — pull specific neighborhoods/landmarks/experiences from the actual footage rather than generic "travel guide" language.

**Series names to use exactly:** "Young & Outside in [Location]," "SCENT PASSPORT."

**Hashtag tiers (mix 3 per post — don't stack one tier):**
1. Broad/discovery — e.g. #traveltiktok
2. Niche/community — e.g. #blackgirltravel
3. Brand/series-specific — #blkgrlcotoo, #youngandoutsidein[location], #scentpassport
- **Never reuse retired series hashtags:** #stamped, #fuckitbookit, #younghotandoutside.

**Titles:** front-load the searchable term (location/topic/series name); match the exact current series name (check against the naming history above — this series has been renamed multiple times); don't duplicate the title phrase on the thumbnail.

## Thumbnail Visual Identity
- No fixed palette locked — pull color direction from the actual destination/footage. Ask rather than invent if a look isn't set yet for a given trip.
- Otherwise follows the general composition/technical rules in `BLKGRLCO-STUDIO-OVERVIEW.md` (face centered and readable, no clutter, don't duplicate title phrase, correct platform specs).
